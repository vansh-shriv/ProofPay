# 00 — Hackathon Brief (what the contest demands)

**Event:** PayPal AI Hackathon — "Build What's Next with PayPal and AI" (Devpost)
**Deadline:** 12 Nov 2026, 8:00pm UTC (winners announced 21 Dec 2026)
**Prizes:** ~$67,500 cash. No tracks, no prescribed problem.

## Hard requirements (disqualifying if missed)
| # | Requirement | How we satisfy it |
|---|---|---|
| 1 | Meaningfully uses >=1 PayPal technology (sandbox) | PayPal MCP server / Agent Toolkit + REST APIs (Invoicing, Orders, Disputes) |
| 2 | Meaningfully uses AI | Claude tool-calling agent that plans and executes PayPal actions |
| 3 | Working prototype, judges can run it | Hosted URL (Render) AND run instructions in README |
| 4 | Text description | Devpost write-up (draft in `docs/05-submission.md`) |
| 5 | Tools used + how | "AI & Tools" section in README |
| 6 | Public repo + visible LICENSE | GitHub public, MIT license |
| 7 | Demo video < 3 min, public YouTube, no copyrighted music/trademarks | Scripted in `docs/05-submission.md` |
| 8 | Comply with Official Rules | Read full rules (user task, see plan) |

## Prize map (what we can stack)
- **Best Overall** 1st $12k / 2nd $8k / 3rd $5k
- **Honorable mentions $5k each:** Most Creative, Most Impactful, Best Demo Delivery, Best Use of PayPal + AI, Best Use of Agentic Commerce
- **Sponsor awards (stackable, optional tools):** AG Grid (up to $5k), APIMatic ($1k), Bryntum ($1k), Channel3 ($1.5k), Render (credits)

No public scoring rubric. Honorable-mention categories hint at what judges value:
creativity, impact, demo delivery, depth of PayPal + AI use, agentic commerce.
